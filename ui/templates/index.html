WSL Stack Checklist

Nếu stack DOWN, kiểm tra Docker Desktop + WSL integration.

  1. Mở Docker Desktop trên Windows và bật WSL2 integration cho distro Ubuntu.
  2. Trong WSL, chạy docker info phải OK (không lỗi daemon).
  3. Khởi động lại: make up hoặc docker compose -f infra/docker-compose.yml up -d.
  4. Nếu vẫn DOWN, kiểm tra logs từng service hoặc kiểm tra cổng 3000/8080/8081.
