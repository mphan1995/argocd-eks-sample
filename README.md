# ArgoCD Lab GitOps

This repository is a **learning lab** for practicing ArgoCD GitOps concepts:
- Sync & Rollback
- RBAC & Project Policies
- Self-healing deployment
- Security policies (Kyverno) - Sử dụng tool Kyverno dể dò 
- Observability (Prometheus, Grafana)

> 💡 Uses fake image (nginx) — no CI/CD pipeline required.

# Jenkins UI: http://localhost:8080
